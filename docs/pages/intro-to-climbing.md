# Intro to Climbing & Belay

## Purpose

Representative Owner Demo V1 program-detail page for first-time climbers considering an introductory roped-climbing and belay course.

## Implemented sections

- Shared site navigation and footer.
- Breadcrumbs and program hero with instructional imagery.
- Class overview metrics.
- Learning outcomes.
- Audience and what-to-bring guidance.
- External booking panel.

## Customer journey

Visitors discover the class from the Classes navigation, understand the intended audience and learning outcomes, review the overview metrics, and follow the external Rock Gym Pro booking link. The First Visit Guide remains available for visitors who need general arrival information.

The booking link is preserved from the existing implementation. It is an external provider dependency and must be checked for current class dates, pricing, availability, and cancellation policies.

## Pending owner confirmation

The following claims are provisional until confirmed:

- Class title and certification naming.
- Minimum age and participant eligibility.
- Duration and additional open-climb time.
- Tuition.
- Included shoes, harness, or belay-device rentals.
- Prerequisites and waiver requirements.
- Certification requirements and credential validity.
- Instructor qualifications.
- Curriculum details and assessment language.
- Booking URL, availability, cancellation, and rescheduling policies.

The page uses concise confirm labels and neutral copy for these items so the demo communicates the intended structure without silently approving business policy.

## Redpoint HQ considerations

Redpoint HQ is the planned future provider for membership account management, not an assumed class-registration provider. This page does not add account-management functionality or infer any Redpoint HQ booking capability.
