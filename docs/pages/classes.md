# Classes

Route: `/classes`. Navigation: Classes. Status: proposed page-family specification.

## Purpose and audience

Help beginners and returning climbers choose appropriate instruction. Main action on each program: **View Dates & Book** → verified Rock Gym Pro offering. Private coaching uses the confirmed staff scheduling process.

## Section order

1. Class overview with beginner, technique, and coaching pathways.
2. Beginner progression: bouldering, top-rope belaying, lead instruction.
3. Technique classes or series.
4. Private coaching details and contact action.
5. Preparation, equipment, and member-discount explanation.
6. FAQs and related youth-program link.

## Reusable program detail

Each program detail includes title, description, photography, ages, experience level, prerequisites, duration, price reference, rental inclusion, learning outcomes, preparation, and booking action. Supporting routes are to be finalized in the migration register.

Keep prerequisites visible before booking. Do not imply introductory classes must be taken in numerical order unless staff confirm that requirement. Distinguish class admission from any climbing access before/after the session.

## Functionality and states

Use provider dates and inventory only when supported. Otherwise provide a direct View Dates & Book action rather than an invented availability selector. Explain that registration continues with the booking provider. Sold-out, cancelled, seasonal, or unavailable offerings need verified status; coaching inquiries must not appear instantly booked.

## Responsive behavior and acceptance

- Cards share the same metadata order and stack on mobile.
- Program selection works without hover interactions.
- Each registration link maps to the correct offering.
- Prerequisites, rental inclusion, and pricing are visible before handoff.
- Provider failure has a usable direct-link/contact alternative.

## Confirmation needed

Active programs, age limits, prerequisites, coaching process, rates, member discounts, and current booking destinations. Follow [website-spec.md](../website-spec.md) and [theme.md](../theme.md).
